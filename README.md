# Taylor Hackett — Personal résumé site

A responsive, static personal résumé website for Taylor Hackett, a Finance and Legal Studies student at Tulane University.

## Preview locally

Open `index.html` in a browser. The site uses Google Fonts when a network connection is available and otherwise falls back to system fonts.

## Publish with GitHub Pages

In the repository settings, open **Pages**, select the `main` branch and `/ (root)` as the publishing source, and save. GitHub Pages will publish the site from `index.html`.

Use the **Print résumé** button in the site to print or save a PDF. Add verified experience, contact details, and professional profile links as they become available.
