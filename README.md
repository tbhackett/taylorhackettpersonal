# Market Terminal

A responsive, Bloomberg Terminal-inspired interactive market dashboard built with plain HTML, CSS, and JavaScript. No build step or package installation is required.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server.

## Interactions

- Select a watchlist ticker to update its quote and chart.
- Use the command line for a ticker (`NVDA`, `AAPL`, `TSLA`) or a panel command (`news`, `portfolio`, `help`).
- Search with `/`, open quick command focus with `⌘ K` / `Ctrl K`, and show shortcuts with `?`.
- Add/remove a selected ticker from the watchlist, change chart ranges, and toggle line/area chart styles.

All market values, headlines, and portfolio figures are fictional illustrative demo data. This prototype does not connect to a real-time feed and is not investment advice.
